              About Foundry

              An entrepreneurial experimentation lab. A hypothesis goes in; a risk-rated assumption board, a five-seat founder council, and an explicit PROCEED / PIVOT / PERISH call come out.

              How it runs on AWS

              • Amazon Cognito — sign-in through the Hosted UI. The API verifies the ID token before attributing a post to you.
              • Claude on Amazon Bedrock — evaluations via the Converse API with forced tool-use, so every response has the same structure and scores stay comparable.
              • AWS Lambda — the API, behind a Function URL.
              • Amazon DynamoDB — the published community board.
              • Amazon S3 + CloudFront — this frontend, over HTTPS, same origin as the API.

              Arithmetic is computed locally, never by the model, and the assumption board and decision are deterministic. If Bedrock is unreachable the app degrades to the local engine rather than failing — the engine in use is always shown in the header. Add your own OpenAI, Anthropic, or OpenRouter key in Settings to re-run the council on a model you already pay for.

              Engine & API keys

              Foundry runs on Amazon Bedrock by default. Add your own key to re-run the Founder Council on a model you already pay for. Keys are stored in this browser only and sent only to this app's own API — never logged, never persisted server-side.
